# RHEL包管理工具

## 前言

RPM Package Manager (RPM)是一个运行在 Red Hat Enterprise Linux (RHEL)、CentOS、Fedora、基于RHEL源码再编译发行的RHEL系列系统均可以使用

## RPM包管理

RPM软件包存在两种形式，一种是源RPM【包含源码和如果构建源码的spec文件】，一种是二进制RPM【可以直接被安装在系统上的RPM包】。下图就是一个 Apache服务器的RPM 安装包

 ![](/assets/img/Linux4/7e84150c-5bc9-4ecb-93c7-3804c0e6e201.png " =408x63")

### 如何使用

一般情况下我们都不会直接使用rpm 命令进行包管理，而是会使用yum或dnf等高级包管理工具进行包管理，这些高级包管理工具本质上也是在管理rpm包，只这些包管理会自动解决版本，依赖等问题，而不需要我们去考虑这些问题

- 安装命令

```bash
rpm -i (软件包名称.rpm)
```

如果直接这条命令安装上面的httpd的rpm那一定会报错

 ![](/assets/img/Linux4/dd4988b3-d23f-4731-bfb3-f9b6506e81a4.png " =1158x168") 因为他缺少两个依赖包，httpd-core和system-logos-httpd。这也就是为什么很少直接使用rpm命令直接进行软件包管理

- 查软件包描述信息

```bash
rpm -qi (软件包名称)
```

- 升级软件包命令

```bash
rpm -u (软件包名称)
```

- 卸载软件包

```bash
rpm -e (软件包名称)
```

## yum/dnf包管理工具

前面也看到了直接使用rpm 命令进行rpm包安装十分的复杂和麻烦，所以就有了yum、dnf等高级包管理工具，安装软件十分的方便，例如我要安装Apache服务器就可以直接使用命令

```bash
dnf install httpd -y
```

 ![](/assets/img/Linux4/de1b4c61-e5e4-4a0d-b33e-d48e06798dbe.png " =1136x664")
 ![](/assets/img/Linux4/7a3853ab-77bd-43ad-b50a-ea4d6d3ea85c.png " =1155x339")

系统会自动解决依赖问题

### 如何使用【仓库源默认位置在国外，国内可能无法访问，查看文章最后的修改yum源】

yum和dnf命令格式一样，如果是Centos7就需要将dnf替换yum，其余格式一样。这里使用dnf 命令做演示

搜索软件包

```bash
dnf search 软件包名
```

或者使用查看仓库列表命令+grep命令进行过滤也能达到查找软件包的效果

```bash
dnf list     #查看仓库列表
dnf list | grep 软件包名
```

安装软件

```bash
dnf install 软件包名1 软件包名2
dnf install 软件包名 -y  #-y参数的意思是安装过程中全部同意

#或者直接安装单个rpm软件包
dnf install 软件包名.rpm
```

更新软件包

```bash
#检查软件包是否需更新
dnf check-update

#跟新单个软件包
dnf upgrade 软件包名
```

删除软件包

```bash
dnf remove 软件包名1 软件包名2
```

## yum原/rpm仓库

在使用yum或dnf包管理工具的时候需有对应的本地或远端仓库才可以正常使用，仓库的配置文件在

`/etc/yum.repos.d/`中，以 `.repo`结尾的文件中

 ![](/assets/img/Linux4/349212c9-20f9-4f04-b249-c82a7e8e05ae.png " =717x111")
 ![](/assets/img/Linux4/7aaf064f-42b6-4292-94e6-cf40ca6f3eea.png " =1143x564")

在了解如何配置仓库之前我们需要先了解一个东西，仓库是如何被定义的

一个仓库他必定会存在一个.xml,.gz的原数据索引文件如果没有这些文件那么这个仓库就无法被识别，下面是一个简单的仓库目录图

```bash
*.repo/
├── repodata/
│   ├── repomd.xml
│   ├── primary.xml.gz
│   ├── filelists.xml.gz
│   ├── other.xml.gz
│   └── ...（可能还有其他元数据文件，如 comps.xml 等）
└── packages/
    ├── package1-1.0-1.x86_64.rpm
    ├── package2-2.3-4.noarch.rpm
```

下我将配置本地yum源来给你讲解yum源仓库

1. 首先请确保CD/DVD的设备状态为已连接
2. 查看硬盘信息【关于磁盘的命令后面的文章会讲】![](/assets/img/Linux4/2d75fd9b-4a9b-4312-a104-42c4b9ce959b.png " =1041x435")

   可以看到上面存在一个SIZE有一个10.7G的行，NAME为sr0，这个sr0就是我们的CD
3. 配置光驱挂载【关于磁盘的命令后面的文章会讲】

   ```bash
   cd /mnt/      #CD到mnt目录下
   mkdir cdrom   #创建一个目录用于后续的挂载

   #将CD挂载到刚刚穿件的这目录
   mount /dev/sr0 /mnt/cdrom/

   ```

   挂载完毕后查看cdrom的内容应如下

   ```bash
   [root@master mnt]# ls cdrom/
   AppStream  BaseOS  EFI  images  isolinux  LICENSE  media.repo

   ```

   和前面所讲述的目录结一致，这里为了更快速的所以在packages目录下添加了按字母排序的目录
4. 配置 `.repo`文件

   ```bash
   cp -r /etc/yum.repos.d /etc/yum.repos.d.bak  #备份原来仓库配置文件
   rm -rf /etc/yum.repos.d/*                    #删除原配置文件
   vim /etc/yum.repos.d/cd.repo                 #新建配置文件，名称随意但是需要以.repo结尾

   ```

   在文件中编辑下面内容

   ```none
   [a]
   name=base
   baseurl=file:///mnt/cdrom/BaseOS
   enable=1
   gpgcheck=0
   ```

   这样本地仓库就编辑好了，下面是对各个字段的解释

   - \[\] 里面填写仓库名称，一个\[\]表示一个仓库，这里的名称需要唯一
   - name 仓库名，也需要唯一
   - baseurl 仓库地址，这里要填写URL地址，file://表示本地，/mnt/cdrom/BaseOS表示本地根目录下的mnt/cdrom/BaseOS。当然这里也可以是网络原 http://aliyun.com/mirror…
   - enable 表示是否启用这个仓库，0为不起启用，1为启用
   - gpgcheck 表示是否启用gpg秘钥，0为不起启用，1为启用
   - gpgkey gpg秘钥路径，如果前面的gpgcheck为1则需要配置此项目
5. 刷新yum源，编辑好 `.repo`文件后执行下面命令刷新仓库信息

   ```bash
   dnf clean all
   dnf makecache
   ```
6. 完成后可以使用dnf repolist命令查看仓库结果

   ```bash
   [root@master cdrom]# dnf repolist 
   repo id                                      repo name
   a                                            base

   ```
7. 完成后我们安装httpd，由于BaseOS基础软件包中没有httpd，所以这里将AppStream仓库也添加了

## 加速地址配置

RockyLinux的默认仓库地址在国外，我们在国内安装rpm包会十分慢，有时可能还连接不上，这时候就需要配置国内进行仓库，这将以[阿里巴巴开源镜像站-OPSX为例](https://developer.aliyun.com/mirror/)

将下面命令复制到系统即可

【RockyLinux】

```bash
sed -e 's|^mirrorlist=|#mirrorlist=|g' \
    -e 's|^#baseurl=http://dl.rockylinux.org/$contentdir|baseurl=https://mirrors.aliyun.com/rockylinux|g' \
    -i.bak \
    /etc/yum.repos.d/Rocky-*.repo

dnf makecache
```

【Centos 7】

```bash
curl -o /etc/yum.repos.d/CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo
```

【Centos 8】

```bash
minorver=8.5.2111
sudo sed -e "s|^mirrorlist=|#mirrorlist=|g" \
         -e "s|^#baseurl=http://mirror.centos.org/\$contentdir/\$releasever|baseurl=https://mirrors.aliyun.com/centos-vault/$minorver|g" \
         -i.bak \
         /etc/yum.repos.d/CentOS-*.repo
```
